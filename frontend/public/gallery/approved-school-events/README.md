# Approved school event photos

Place only public-approved Tumaini Academy event photos in this folder.

Recommended file names:

- `classroom-learning.jpg`
- `school-event.jpg`
- `games-and-talent.jpg`
- `boarding-and-care.jpg`

After adding a photo, update `eventGallery` in `frontend/src/App.tsx` with a matching path such as:

```ts
imageSrc: "/gallery/approved-school-events/classroom-learning.jpg"
```

Use learner photos only when the school has permission or parent/guardian consent for public website use.
