# Tumaini event gallery

These folders are copied from `assets/Tumaini Images` so the public website can serve the photos directly.

Current albums:

- `corpus-christi-sunday`: parish faith celebration and Catholic identity.
- `redcross-event`: community safety, awareness, teamwork, and service.
- `scout`: outdoor formation, discipline, leadership, and learner confidence.

When adding a new event folder, place the photos here and add a matching album entry in `frontend/src/App.tsx`.
